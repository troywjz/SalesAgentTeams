# SalesAgentTeams 作品简介

作品名称：SalesAgentTeams——企业销售多智能体协同系统

参赛者：troywjz｜个人开发者

SalesAgentTeams 面向企业销售咨询中的“回复正确但不会推进、知识引用不稳定、风险边界不清晰”等问题，将流程拆分为意图识别、SOP 决策、知识检索、回复生成、安全审核和记忆更新六个 Agent，并一一映射为六个 AgentTeams Worker。原有 LangGraph 保留为业务状态与流程内核，AgentTeams 负责外层协同，MCP 负责能力适配。

每个 Worker 强制绑定版本化 SKILL，明确输入输出、触发条件、失败处理、验证方式和权限边界；`evidence-handoff` Skill 统一记录任务、版本、工具调用、证据和人工接管。系统提供可运行的销售 Agent Bridge MCP，以及离线评估和 3D 指标热力图 MCP，生成回放结果、盲评模板、评分报告和自包含 HTML 热力图。项目提供本地演示、MCP HTTP 服务、Worker 清单和 Docker 说明，公开样例仅使用演示数据，代码、Skill、MCP 契约、比赛材料和复现命令均在 GitHub 开源。

> 注：正式评估分数必须来自授权数据和人工盲评；未完成盲评时，项目只生成运行结果和盲评模板，不虚构分数。
