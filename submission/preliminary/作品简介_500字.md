# SalesAgentTeams 作品简介

作品名称：SalesAgentTeams——办公技能培训销售多智能体协同系统

参赛者：troywjz｜个人开发者

SalesAgentTeams 面向办公技能培训咨询中“回复正确但不会推进、课程与价格引用不稳定、数据安全和交易边界不清晰”等问题，将销售流程拆分为记忆读取、意图识别、SOP 决策、知识检索、回复生成、安全审核和记忆更新，并把六个业务 Agent 一一映射为六个 AgentTeams Worker。Conversation Worker 同时承担 Team Leader，负责拆解任务和汇总证据；原有 LangGraph 保留为业务状态与流程内核，AgentTeams 负责外层协同，MCP 提供角色受限工具。

每个 Worker 强制绑定版本化 Skill。项目共提供 10 个 Skill，明确目的、输入输出、触发条件、依赖工具、失败处理、安全边界、复用价值、多 Agent 关系和验证方法；`evidence-handoff` 为所有 Worker 统一记录任务、版本、工具、证据、错误和人工接管。系统提供 Sales Agent Bridge MCP，以及离线评估与 3D 指标热力图 MCP；没有人工评分时只生成回放和盲评模板，不虚构分数。

开源 Demo 内置 Excel、Word、PPT、AI 办公和企业流程等公开样例。Web、数据库和原会计项目完全隔离，运行时强制数据库名为 `sales_agent_demo`；默认使用确定性本地模型，不需要外部 API，也不会产生 LLM token 费用。公开仓库包含代码、Agent Identity、Worker 清单、Skill、MCP 契约、测试、运行手册、合规检查和初赛 PPT/PDF，可由评委按命令复现。

既有授权离线盲评的 144 个脱敏回合显示，系统总分 80.00，真人基线 64.44，优势主要来自合规和意图推进；该结果只有一名评审且是单轮离线对比，不能证明转化率提升。本次比赛不重跑原盲评，只引用汇总结论并用无真实 API 测试验证工程链路。
