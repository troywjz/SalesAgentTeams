# SalesAgentTeams 作品简介

作品名称：SalesAgentTeams——网络销售多智能体系统

参赛者：王嘉桢｜个人开发者

SalesAgentTeams 面向 To C 网络销售中“会回答但不会持续推进”的问题，将每轮交流转化为客户状态、销售阶段和后续任务。适配企业知识、销售 SOP、案例、风险规则和渠道数据即可迁移到不同行业。系统按阶段、SOP 与超时规则推进，风险和复杂决策转人工。

六个业务 Agent 映射为六个 AgentTeams Worker。Conversation Worker 兼任 Team Leader，统一传递任务与证据；LangGraph 负责路由、检索、Safety 复审、落库与调度。10 个版本化 Skill 固化输入输出、工具权限、失败处理和安全边界；两个 MCP 提供角色受限工具与离线评估。

开源项目提供公开样例、PostgreSQL、三端 Web 与一键脚本。正式展示启用三供应商回退与向量 RAG，零 API 回归验证工程链路；89 项测试、6 Worker、10 Skill、2 MCP 均通过。144 回合单评审离线盲评显示系统在合规和推进上占优，办理服务与直接答疑仍需加强；该结果不代表真实转化率提升。
