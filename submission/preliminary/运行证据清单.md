# 初赛运行证据清单

## 当前可复现证据

| 证据 | 命令或路径 | 说明 |
|---|---|---|
| 六 Worker 本地链路 | `python scripts/run_demo_team.py` | 无外部 API 的确定性演示 |
| 离线评估样例 | `evaluation/datasets/demo_cases.csv` | 公开、脱敏演示数据 |
| 评估 MCP | `python -m mcp_servers.evaluation_insights --transport stdio` | 运行、评分、热力图三工具 |

| 自动化测试 | `python -m pytest -q` | 原项目基线与新增测试 |
| 开源审计 | `python scripts/check_open_source.py` | 检查追踪文件、私有数据和明显密钥 |

## 评估证据边界

- 演示模型结果用于验证流程和产物格式，不代表生产效果。
- 正式分数必须由授权数据和至少两名销售领域盲评人员产生。
- `盲评映射.csv` 只供汇总程序使用，不交给评审人员。
- 3D 热力图只读取评分明细，不自行产生评分。

## AgentTeams 证据

AgentTeams 运行需要 Docker Desktop、官方 AgentTeams 和 LLM 凭据。执行 `agt apply` 后，应记录 Worker/Team 状态、MCP 工具列表和一次完整的 Manager → Team Leader → Worker → Safety Worker 任务轨迹。若本机 Docker 未启动，只报告本地与 MCP 模式结果，不把清单部署误写成已运行。
