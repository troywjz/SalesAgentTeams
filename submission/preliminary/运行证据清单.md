## 评估证据边界

- 演示模型结果用于验证流程和产物格式，不代表生产效果。
- 历史盲评汇总结论见 `历史评测与验证报告.md`；原始数据和逐轮评分不进入开源仓库。
- 新的正式分数必须来自授权数据和独立人工评分；缺少评分时不输出分数。
- 3D 热力图只读取评分明细，不自行产生评分。

## 受控真实 API 试运行

2026-08-12 在独立 `18101` 临时进程执行一次办公技能销售完整链路，使用
`deepseek-v4-flash` 非思考模式、单一供应商、每节点最多一次尝试，关闭
RAG 向量、自动跟进和后备模型。中文客户消息完整入库，Intent、Knowledge、
SOP、Conversation、Safety、Memory 六个 LLM Agent 各调用一次并全部成功；
七个图节点全部成功，无回退、无人工接管，阶段推进到“探需扩需A”。该轮
共 13,069 输入 token、875 输出 token、13,944 总 token。验证后临时进程已
停止。真实 API 试运行仅用于确认 Web/LangGraph 主链路；日常回归仍由 `verify_demo.ps1` 强制切换到零 API 模式。公开模板现为正式展示配置，复制后只需填写 `DEEPSEEK_API_KEY`，启动前门禁会阻止密钥缺失时静默降级。
