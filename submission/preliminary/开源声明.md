# 开源声明

## 项目身份

- 项目：SalesAgentTeams
- 参赛者：troywjz｜个人开发者
- GitHub：`https://github.com/troywjz/SalesAgentTeams`
- 许可证：AGPL-3.0

## 来源与新增内容

项目以现有公开销售 Demo 为基础，在独立仓库中保留原有 LangGraph、FastAPI、评估和知识快照代码；新增 AgentTeams Worker 清单、Skill、MCP 适配层、评估热力图、Docker 文件和比赛资料。新仓库不携带原 Git 历史、`.env`、本地虚拟环境、私有聊天数据和历史评估结果。

## 依赖与凭据

Python 依赖记录在 `requirements.txt`。AgentTeams、MCP SDK 和 Plotly 只作为公开依赖使用。模型 API Key、数据库密码和 MCP Gateway 凭据只能放在本地 `.env` 或部署平台的 Secret 中，不能写入 Worker 包、Skill 或 Git。

## 数据与评估

仓库中的评估样例和知识快照用于演示，不包含真实客户身份信息。正式评估应使用经过授权、去标识化的数据，并分别保存原始数据、盲评表、映射表和最终报告。项目不会把确定性演示结果宣传为转化率提升或生产效果。
