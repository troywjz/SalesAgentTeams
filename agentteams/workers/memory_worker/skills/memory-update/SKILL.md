# Memory Update Skill

版本：1.1.0

## 目的

以最小必要原则保存会话摘要和客户需求，支持跨回合连续性。

## 输入

会话摘要、客户画像、当前消息和本轮 Worker 输出。

## 输出

历史摘要、允许保存的画像增量、更新状态和证据。

## 触发条件

回合开始时读取；Safety 完成后再更新。

## 依赖工具

Sales Agent Bridge MCP 的 `run_memory_agent`、独立 `sales_agent_demo` 数据库、`evidence-handoff`。

## 失败处理

记忆不可用时不阻塞安全回复；返回降级状态并记录错误。

## 安全边界

只保存业务必要信息，过滤敏感字段，支持删除；不得访问原会计业务库或未授权聊天。

## 复用价值

可复用于客服、销售和客户成功系统的受控长期记忆。

## 多 Agent 流程关系

为 Intent 和 Conversation 提供历史上下文，并在回合完成后接收经审核结果。

## 验证

校验读写分离、敏感字段过滤、更新可追踪和数据库名护栏。
