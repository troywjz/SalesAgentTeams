# Memory Update Skill

版本：1.0.0

## 输入

会话摘要、客户画像、当前消息和本轮 Worker 输出。

## 输出

返回历史摘要、允许保存的客户画像增量和记忆更新证据。

## 触发与边界

回合开始时读取，回合结束时更新。只保存业务必要信息，遵守授权、最小化和可删除原则。

## 失败处理

记忆不可用时不阻塞客户可见回复；返回降级状态并记录证据。

## 验证与复用

验证读写模式分离、敏感字段过滤和更新可追踪。可复用于客服、销售和客户成功系统。
