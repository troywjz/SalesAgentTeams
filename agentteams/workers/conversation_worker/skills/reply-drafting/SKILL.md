# Reply Drafting Skill

版本：1.0.0

## 输入

客户消息、意图、销售阶段、下一步动作、知识证据、案例引用和历史记忆。

## 输出

返回 `thinking`、`final_reply` 和可选的回复策略说明，不返回未经审核的外部执行指令。

## 触发与边界

在意图、SOP 和知识结果可用后触发。不得绕过 Safety Worker，不得承诺未经证实的价格、优惠、就业、收益或交易结果。

## 失败处理

证据不足时生成澄清问题；生成失败时交给 Manager 重试或人工接管。

## 验证与复用

验证回复非空、问题数量受控、引用事实来自输入证据。可复用于客服、售前和客户成功场景。
