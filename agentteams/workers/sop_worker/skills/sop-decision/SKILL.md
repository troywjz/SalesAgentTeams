# SOP Decision Skill

版本：1.0.0

## 输入

客户消息、意图结果、当前销售阶段、可选阶段列表和会话状态。

## 输出

返回 `current_stage`、`next_action`、`should_transfer`、`reason`。

## 触发与边界

意图识别成功后触发。只能从受控销售阶段中选择，不得绕过安全审核或直接执行付款、合同等外部动作。

## 失败处理

阶段无法确定时保留当前阶段并请求 Manager 补充上下文；涉及交易确认时优先标记人工接管。

## 验证与复用

验证阶段值属于允许列表、下一步动作非空、转人工条件可解释。可复用于其他有阶段化流程的业务。
