# Safety Review Skill

版本：1.1.0

## 目的

在客户可见回复发送前执行强制事实与风险门禁。

## 输入

客户消息、草稿、意图、SOP、知识引用、数据安全提示和风控规则。

## 输出

`action`、`approved_reply` 或 `revised_reply`、风险列表、接管原因和交接摘要。

## 触发条件

所有客户可见自动回复发送前强制触发。

## 依赖工具

Sales Agent Bridge MCP 的 `run_safety_agent`、专属风控规则、`evidence-handoff`。

## 失败处理

服务异常、证据冲突、风险不确定或涉及交易与敏感数据时默认转人工。

## 安全边界

不得删除风险证据，不把人工审核伪装为自动完成，不自行执行交易或处理敏感文件。

## 复用价值

可替换规则库复用于受监管客服、售前和内容审核链路。

## 多 Agent 流程关系

审核 Conversation Worker 草稿并决定闭环结果；其结论优先于其他业务 Worker。

## 验证

用价格、付款、隐私、AI 未核验、投诉和普通咨询样例验证放行、改写、转人工三类结果。
